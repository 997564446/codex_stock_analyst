# 收盘之后 · A 股个人短线复盘

本机使用的单账户交易账本：手工录入成交，自动核算资金和费用，保存免费行情，调用已登录的 Codex 生成有证据的复盘。技术栈为 Python / FastAPI / Jinja2 / JavaScript / SQLite / AKShare。

## 启动

本机依赖已经安装，在终端运行：

```sh
cd /Users/uziman/project/uziman_codex_stock_analyst
./run.sh
```

打开 <http://127.0.0.1:8765>。保持终端运行，结束时按 `Ctrl+C`。仅监听本机，使用单个服务进程，不要加 `--workers` 或对外部署。

新电脑建议使用带 OpenSSL 的 Python 3.11 或更新版本；代码兼容 Python 3.9。本机 Python 3.9 / LibreSSL 会产生 urllib3 兼容性警告，已实测请求可用，但新环境不建议沿用该旧运行时。第一次运行 `run.sh` 会新建 `.venv` 并安装运行依赖；已有不完整虚拟环境时运行：

```sh
.venv/bin/python -m pip install -r requirements.txt
```

`requirements-lock.txt` 记录本次验收所用的依赖版本（Python 3.9 / macOS ARM64）。如需复现同一环境，可使用该文件安装。

## 第一次使用

1. 在「设置与备份」填写专用于这套短线操作的初始资金。默认示例为 10,000 元，不代表已读取券商余额。
2. 在「交易记录」填写股票代码和名称、成交日期时间、成交均价、股数，以及买入时预期的当日收盘价。价格不含费用。可展开填写标签、备注、记录时点、截图。
3. 有交割单时选「已核对交割单」，填写四项实际费用；没有时暂用估算，之后更正。
4. 「每日交易」先选择日期，连续录入当天多只股票。录入后自动尝试获取行情。「AI 复盘」默认按日期分析整日操作，也可切换单股持仓周期。默认不发送截图，勾选后发送本次范围内的截图。
5. 在「资金总览」查看现金、持仓及总资产，在「交易统计」查看已清仓交易周期的结果。
6. 定期下载完整 ZIP 备份。JSON 导出便于阅读分析；恢复入口使用完整 ZIP。

示例交易只存在于自动测试和临时验证环境，正式账本没有预填样例。

## 记账口径

- 所有金额使用 `Decimal`，按分结算；不依赖 AI 或浏览器浮点数记账。
- 按上海时间、成交时间及同时间的录入顺序重放。录入同一秒的资金和成交时，先录入确实先发生的操作。
- 买入减少现金并增加含买入费成本。加仓使用移动加权成本；部分卖出按比例分摊到分，清仓带走全部剩余成本，避免尾差。
- 同一股票从空仓到再次清仓为一个周期，周期收益包含买卖费用。未清仓周期不进入胜率统计。
- 卖出检查持股数量和当日可卖数量。出金或成交导致负现金时整笔拒绝；无融资能力，不允许靠未来入金支持过去买入。
- 更正、删除会重算后续流水，不合法则回滚。审计历史包含于完整备份。
- 入金出金属于本金变动，不计利润。初始资金是账本开始前的资金；已有持仓需要补录其实际买入及对应资金。
- 总资产 = 现金 + 有明确时间的行情估值。缺少任一持仓报价时不假定为零，总资产显示「待补行情」。持仓市值是标注时点的估值，不是实时价格。
- 每次买入在有收盘行情后显示预期价与实际收盘价；复盘输入同时包含程序计算的当日含买入费浮动盈亏与当前持仓。
- 统计中“成本仓位”是首次买入含费支出占当时现金加其他持仓成本的比例；不是当时总市值仓位。现金占比单独分组。
- 涨幅用未复权前收盘价计算，前收盘缺失或距离超过七天时归为未知。登记过公司行为调整的股票归为未知，不能将除权影响误作下跌。
- 分红和送转需要用户核对后登记：税后现金分红降低未收回成本，超出成本部分计收益；股份调整保留总成本。仅适用于已到账、已可用股份。配股、税款补扣、复杂重组需另行核对，不自动处理。

## 费用配置：个人推断，尚非券商确认规则

默认净佣金率 `0.000171`（万分之 1.71）；净佣金、经手费、证管费和过户费分别向上取整到分，净佣金加规费最低合计 5 元；印花税四舍五入到分。沪市过户费单列，深市归入其他费用。它能复现已提供的三笔交割数据，但不能据此保证所有订单完全一致。

| 验收样例 | 核算结果 |
| --- | --- |
| 内蒙新华：200 股，14.20 买、14.40 卖 | 买入支出 2,845.03；卖出到账 2,873.53；净赚 28.50；一万元变为 10,028.50 |
| 益生股份：4,160 股，10.99 卖 | 印花税 22.86；单列过户费 0；佣金 7.82；其他费用 2.94；到账 45,684.78 |

实际费用优先。配置变更只作用于后续新建交易；更正旧交易沿用原估算配置快照。对 2023-08-28 之前的成交要求填写实际费用，避免套用当前税费。第一版不支持 2023 年之前的记录。

## 行情与 AI

- 股票日线：东方财富优先，失败后尝试腾讯；一分钟行情：东方财富优先，失败后尝试新浪；沪深 300：东方财富优先，失败后尝试腾讯。
- 板块：仅尝试用户明确填写的东方财富行业。未选择或接口失败时标注缺失；不推断历史行业归属，不用今天的板块涨跌替代过去。
- 每次请求有 35 秒硬超时，成功数据按时间合并保存，更新失败不删除历史数据。来源可能交替，逐行保留来源；成交量单位未统一时不跨来源比较。
- 国内行情子进程默认直连，不改全局代理。需要继承系统代理时设置 `STOCK_MARKET_PROXY=1`。
- 分钟数据只能取得近期片段，历史缺口可能无法补齐。单次复盘按每次买入最多提供 120 条此前分钟线及 30 条此前日线；事后每类最多 1,500 条，原始总数会随资料传递。完整已获取数据在本地和导出中保留。
- 软件关闭或电脑休眠时不会采集。更新由录入或按钮触发，没有无人值守保证。
- 每笔买入的证据排除成交所在分钟及当日完整日线；事后资料另列。报告风险引用必须对应已提供的买入前证据 ID，其他报告结构也会验证。文字推理仍需用户复核，引用校验不能证明 AI 解释一定正确。
- 报告保留原始输入快照和账本修订号。修改交易、费用或截图后会标记已有报告需要重新复盘。
- 默认复盘所选日期的整日操作；单股模式分析最近一个持仓周期，历史报告继续保留。

### Codex 账号调用

优先使用 macOS ChatGPT 应用自带的新版 CLI，找不到时使用 PATH 中的 `codex`。本机旧 PATH 版本不能正确读取现有配置，新版实测正常。

使用 `codex exec --ignore-user-config --ephemeral --sandbox read-only`，保留账号登录，忽略不兼容全局配置。分析放在临时目录，只传入本次资料和用户选中的截图，报告由后台保存。不会调用券商或下单。

程序检测 `~/.codex/auth.json`（或 `CODEX_HOME`）中的账号登录类型，不保存登录内容；拒绝 API Key 模式，并清除子进程中的 API Key 环境变量。不自动回退到 API 付费。只用系统钥匙串保存的登录目前无法通过此检查，需使用 CLI 的账号文件登录方式。

在「AI 复盘」页面选择模型和推理强度，选择会保存在当前浏览器。默认模型 `gpt-6.1-sol`（可通过 `STOCK_CODEX_MODEL` 设置受支持的默认模型），默认强度 `high`。不同模型支持的强度不同，账号权限以实际调用为准；失败不会自动更换模型。新报告显示本次提交的模型和强度，历史报告未记录的配置不补猜。登录失效、限额、超时、结构错误都会显示失败并保留账本，可重新点击。单次 AI 请求等待上限通常为 240 秒，max/ultra 强度为 600 秒；复盘会消耗账号的 Codex 使用额度。

可配置环境变量：

| 变量 | 用途 |
| --- | --- |
| `STOCK_PORT` | 本地端口，默认 8765 |
| `STOCK_DATA_DIR` | 数据目录，默认项目 `data/` |
| `STOCK_CODEX_BIN` | 指定 Codex 可执行文件 |
| `STOCK_CODEX_MODEL` | 指定账号支持的模型 |
| `STOCK_MARKET_PROXY=1` | 行情请求继承系统代理 |

## 数据保存与恢复

`data/ledger.sqlite3` 保存流水、费用快照、行情、任务、报告及审计记录；`data/images/` 保存重新编码后的截图。数据目录不进入版本管理。

完整备份使用 SQLite 在线备份，再加入被引用截图。恢复前校验数据库、账本和图片路径；自动保存 `data/before-restore-*.zip`。有后台任务时不允许恢复，以免写入新旧数据混杂。仅在本机使用，不要把服务公开到互联网。

### 每日交易工作台与整日复盘

在「每日交易」选择日期，可连续录入当天不同股票的成交；保存后保留日期，流水按时间排列，也可勾选查看全部历史。每日说明单独保存，并随完整备份保存。

「AI 复盘」默认按日期分析日初已有持仓、全天买卖和资金变化、日末持仓，一次整日复盘只调用一次 AI。切换到「单股持仓周期」仍可使用原有单股复盘。历史报告保留，历史整日分析不纳入后续交易和后续行情。

卖出兑现盈亏包含跨日持仓收益；账户日盈亏剔除出入金，并要求前值和本日收盘估值齐全。缺行情、尚未收盘，或节假日前值日期无法确认时留空，不使用最新价格替代。成本仓位不是实时市值仓位。

每日说明视为事后记录。整日报告区分事实、主要解释、替代解释和验证条件；没有足够行情时仍分析可确认的操作事实。截图默认不发送，勾选后只发送本次复盘范围内的截图。
